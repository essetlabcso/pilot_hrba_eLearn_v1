# Interaction Block Library

## Purpose

Defines approved reusable blocks. AI Studio must build screens only from these patterns unless a screen-specific spec overrides them.

## Platform blocks

- **P1 UNICEF Top Strip**: turquoise strip with **unicef | for every child**.
- **P2 Agora Header**: hamburger **Menu**, orange **AGORA**, search field **Search all activities**.
- **P3 Breadcrumb Trail**: green home icon and pale-green tabs.
- **P4 Course Information Card**: partnership statement, EU/UNICEF logos/placeholders, course aim.
- **P5 Course Instructions Card**: heading, pop-up warning, 85% certificate warning.
- **P6 Module Tile Grid**: image thumbnails, titles, lock/completion states.
- **P7 Table of Contents Panel**: **View Summary**, list items, active/completed states.
- **P8 Component Launch Wrapper**: launch failure message and **Click to Launch Manually**.

## Player shell blocks

- **C1 Player Header**: logo area, module title, slide subtitle, counter, nav arrows.
- **C2 Progress Strip**: thin yellow strip.
- **C3 Left Toolbar**: fixed controls in exact order.
- **C4 Help Overlay**: dark overlay, arrows, labels, OK, Accessibility.

## Slide blocks

- **S1 Start Screen**: split dark teal/photo layout, Start button.
- **S2 Welcome Video Slide**: pastel blocks, centered video placeholder, **CHILD RIGHTS TOOLKIT**.
- **S3 Objective/Purpose Slide**: journey/mountain background and objective bars.
- **S4 Learning Outcomes Card Slide**: numbered outcome cards.
- **S5 Interactive Audience Cards**: two cards with plus buttons and modals.
- **S6 Course Structure Progressive Reveal**: initial, partial, full reveal states.
- **S7 Photo + Text Concept Slide**: photo background, translucent text panel, clickable links.
- **S8 Example Card Interaction Slide**: five cards, hover overlay, card modals.
- **S9 Speech Bubble Question Slide**: character, skyline, speech-bubble links.
- **S10 Legal/Framework Panel**: pale peach panel and info/resource area.
- **S11 Timeline/Numbered Node Interaction**: nodes 1–8 and detail panel.
- **S12 Single-Choice Knowledge Check**: pale-blue question panel, radio answers, feedback.
- **S13 Download/Resource Diagram Slide**: diagram, download button, info panel.
- **S14 Resource Document View**: document/PDF-style view.
- **S15 Sticky Note Slide**: pale-green notes and pending detail states.
- **S16 Process Diagram Slide**: two-step CCA diagram.
- **S17 Case Study Intro Slide**: character, speech bubble, Case description button.
- **S18 Case Study Question Slide**: radio options, Case description, Check your answer.
- **S19 Solution State**: selected option, red X marks, green check.
- **S20 Case Summary Slide**: left text, right cotton field image.
- **S21 Module Quiz Intro Slide**: dark overlay, centered quiz intro.
- **S22 Scored Quiz Question Slide**: radio options and **Send your answer**.
- **S23 Quiz Result Slide**: score banner, result message, retry/review buttons.
- **S24 Tabbed Module Summary**: tabs and active content.
- **S25 Completion/Exit Slide**: congratulations, Exit button.

## Modal blocks

- **M1 Standard Information Modal**
- **M2 Case Description Modal**
- **M3 Correct Feedback Modal**
- **M4 Incorrect Feedback Modal**
