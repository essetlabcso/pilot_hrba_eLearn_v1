# Module 1 Visual Asset Briefs — HRBA E-learning Course

## Purpose

This file provides concise production briefs for the priority visual assets needed for Module 1 of the HRBA e-learning course.

Use this file to guide:

- AI image generation
- SVG / React visual component creation
- Codex implementation
- visual consistency checks
- future asset replacement

## Scope

Module 1 only.

These assets support the Module 1 quality upgrade and should align with the existing HRBA course visual identity.

---

## Shared Visual Direction for All Assets

### Overall style

- premium, clean, modern educational visual style
- suitable for a professional HRBA e-learning course
- locally grounded for Ethiopia / East Africa without stereotypes
- respectful, calm, and human-centered
- instructional rather than decorative
- minimal but warm
- polished and web-ready

### Palette direction

Use a refined palette aligned with:

- deep navy
- pale mint
- soft green
- white
- subtle teal accents
- accessible dark text
- restrained warm accent where useful

### Design requirements

- strong readability
- high contrast
- clear hierarchy
- simple composition
- no unnecessary decoration
- no logos
- no watermarks
- no heavy text blocks
- short labels only where needed
- consistent line weight and shape language
- export-friendly
- easy to integrate into the web application

### Accessibility requirements

- do not rely on color alone to communicate meaning
- use labels, connectors, icons, borders, or arrows where meaning matters
- ensure text/label contrast is strong
- avoid tiny text
- support alt text or visually hidden descriptions when used in the app
- decorative details should not distract from the learning message

# Asset 1 — Water Project Story Visual

## File name

```text
m1-s1-04-water-story-placeholder.png
```

## Screen

```text
M1-S1-04 — Water Project Story
```

## Asset type

Scenario visual / polished placeholder image

## Priority

Medium to High

## Purpose

Give emotional and contextual grounding to the water-access story screen.

The asset should help learners feel the real-world relevance of HRBA without becoming dramatic, stereotyped, or charity-poster-like.

## Learning function

This visual should support the idea that a project can exist, but access may still be unequal because people experience distance, safety, information, timing, mobility, or social barriers differently.

## Scene concept

Create a respectful illustrated community water-access scene in Ethiopia / East Africa.

The scene may include:

- a shared water point or hand pump
- a small community setting
- people waiting or discussing access
- signs that access is not equal for everyone
- subtle cues about distance, mobility, safety, information, or social position
- a calm learning-oriented mood

## What to avoid

- no dramatic suffering imagery
- no charity appeal style
- no stereotypes
- no identifiable real people
- no crowded composition
- no excessive text
- no logos or branding
- no watermarks

## Composition

- horizontal 16:9 format
- visually balanced
- enough breathing room for course layout integration
- should work well inside a card or image panel
- should not require text overlay to be meaningful

## Suggested alt text

```text
Illustration of a community water point where people experience access differently, showing that a project can exist while inclusion and fair access still need attention.
```

## AI image generation prompt

```text
Create a polished 16:9 scenario visual for an HRBA e-learning screen titled “Water Project Story.”

Show a respectful, realistic-but-illustrated community water access context in Ethiopia / East Africa. The scene should include a shared water point or hand pump and suggest that access is uneven. Some people should appear affected differently by distance, waiting time, safety, mobility, information, or social position.

The image should feel warm, human-centered, calm, professional, and suitable for an educational course. It should not look like a charity poster or emergency appeal. Avoid stereotypes, dramatic suffering, identifiable real people, logos, or watermarks.

Use a refined palette aligned with deep navy, pale mint, soft green, white, and subtle teal accents. Keep the composition clean, premium, modern, and easy to integrate into a web course screen. No heavy text blocks. No UI frame. Horizontal 16:9 composition.
```

# Asset 2 — Accountability Actor Map

## File name

```text
m1-s2-01-accountability-actor-map.svg
```

## Screen

```text
M1-S2-01 — Who Has Responsibility?
```

## Asset type

Instructional diagram / actor map

## Priority

High

## Purpose

Help learners understand the relationship between rights-holders, duty-bearers, and CSOs in an HRBA approach.

## Learning function

This visual should make clear that responsibility is not only about delivering a service. HRBA also asks who has rights, who has duties, how people can raise concerns, and how response/accountability happens.

## Required concepts

Show:

- Rights-holders
- Duty-bearers
- CSO / local CSO as facilitator, bridge, supporter, or accountability enabler
- feedback / accountability connection
- responsibility beyond direct service delivery

## Suggested labels

Use short labels only:

```text
Rights-holders
Duty-bearers
Local CSO
Voice / Feedback
Responsibility
Response
```

## Suggested structure

A clean triangular or bridge structure:

```text
Rights-holders  <—— voice / feedback ——>  Local CSO  <—— support / advocacy ——>  Duty-bearers
Rights-holders  <—— response / accountability ——>  Duty-bearers
```

Alternative layout:

- rights-holders on left
- duty-bearers on right
- local CSO in the center as bridge
- circular feedback/accountability loop around them

## Design direction

- clean flat vector infographic
- white or pale mint background
- deep navy labels
- teal connectors
- soft green supporting panels
- rounded shapes
- arrows or loop connectors
- no clutter
- no long explanations
- suitable for recreation as SVG or React component

## Accessibility note

The diagram should have a text alternative explaining:

```text
Rights-holders can raise voice and feedback; duty-bearers have responsibility to respond; local CSOs can support participation, communication, and accountability without replacing duty-bearers.
```

## AI image generation prompt

```text
Create a clean flat vector-style instructional diagram for an HRBA e-learning course screen titled “Who Has Responsibility?”

The diagram should show three main actors: Rights-holders, Duty-bearers, and Local CSO. Show the Local CSO as a facilitator, bridge, supporter, or accountability enabler. Show voice/feedback moving from rights-holders and response/accountability from duty-bearers. Make clear that responsibility is more than direct service delivery.

Use short labels only: Rights-holders, Duty-bearers, Local CSO, Voice / Feedback, Responsibility, Response.

Design style: premium modern educational infographic, deep navy text, pale mint and white background, soft green and subtle teal accents, rounded shapes, clean connectors, strong contrast, minimal text, no logos, no watermarks, no UI mockup. Make it easy to recreate later as SVG.
```

# Asset 3 — Services-to-Rights Shift Pathway

## File name

```text
m1-s2-03-services-to-rights-pathway.svg
```

## Screen

```text
M1-S2-03 — From Services to Rights
```

## Asset type

Pathway infographic / shift diagram

## Priority

Medium to High

## Purpose

Help learners understand the shift from service delivery to a rights-based approach.

## Learning function

The asset should show that HRBA does not reject services. It expands service delivery by asking about access, inclusion, participation, voice, responsibility, accountability, dignity, and rights outcomes.

## Required pathway stages

Show progression from:

1. Activity / Service delivery
2. Access + Inclusion
3. Participation + Voice
4. Responsibility + Accountability
5. Dignity + Rights outcomes

## Suggested labels

Use short labels:

```text
Service
Access
Inclusion
Voice
Responsibility
Accountability
Dignity
Rights
```

or:

```text
Service delivery
Access & inclusion
Participation & voice
Responsibility & accountability
Dignity & rights
```

## Suggested structure

Use one of these:

- left-to-right pathway
- bridge
- stepping stones
- guided journey
- before/after progression
- upward improvement path

## Design direction

- clean vector infographic
- strong forward movement
- minimal text
- clear arrows or step connectors
- deep navy labels
- pale mint / white background
- teal and soft green accents
- polished, calm, professional
- suitable for web integration
- easy to recreate as SVG or React component

## Accessibility note

The visual should have a text alternative explaining:

```text
The pathway shows that HRBA moves from simply delivering a service toward improving access, inclusion, participation, responsibility, accountability, dignity, and rights outcomes.
```

## AI image generation prompt

```text
Create a clean flat vector-style pathway infographic for an HRBA e-learning course screen titled “From Services to Rights.”

Show a clear progression from:
1. Service delivery
2. Access & inclusion
3. Participation & voice
4. Responsibility & accountability
5. Dignity & rights

Use a pathway, bridge, stepping-stone, or forward journey layout. The visual should show that HRBA builds on service delivery by adding inclusion, voice, responsibility, accountability, dignity, and rights outcomes.

Use short labels only. Use a premium modern educational style with deep navy text, pale mint and white background, soft green and subtle teal accents. Use rounded shapes, simple arrows, clear hierarchy, strong contrast, and minimal decoration. No logos, no watermarks, no UI mockup. Make it easy to recreate later as SVG.
```
