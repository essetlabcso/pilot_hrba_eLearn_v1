# Global Screen Standard for HRBA Course Refinement V1

Date: 2026-06-08

## Core standard

Each learner-facing screen should behave like a focused premium e-learning slide. On desktop, the learner should be able to see and complete the full screen without vertical scrolling.

## Required screen qualities

1. One clear learning purpose.
2. One main learner action.
3. Short learner-facing text.
4. Strong visual hierarchy.
5. Purposeful use of icons, visuals, or interaction.
6. No hidden content below the fold on desktop.
7. Completion logic connected to the intended interaction.
8. Menu title, top title, and screen count aligned.
9. Accessibility labels, alt text, focus order, and keyboard support.
10. Safe reflection language where learners enter text.

## How to handle content overload

If a screen is too long, use this order:
1. shorten;
2. convert text into cards;
3. convert details into reveal;
4. use progressive display;
5. split into multiple screens;
6. move reference detail to glossary/resources.

## Prohibited patterns

- Long scroll-heavy content screens.
- Static content dump.
- Placeholder block type errors.
- “Unrecognized block layout” messages.
- Text hidden behind sticky header.
- Required interaction that does not unlock Continue.
- Learner-facing development language such as “next screen,” “block type,” or internal IDs.
