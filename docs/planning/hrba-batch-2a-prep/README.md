# Batch 2A Worked-Example Preparation Package

## Purpose

This package prepares Batch 2A before any source edits. It identifies the high-load practice screens that need worked examples, drafts a concise worked-example library for human review, and defines a reusable instruction pattern for complex practice screens.

Batch 2A should improve scaffolding only after the examples and instruction patterns are approved. This package does not implement course fixes.

## Target Modules And Screens

Batch 2A targets complex practice and high-load task screens in Modules 2-5:

- Module 2: matching, participation rating, accountability loop, feedback-loop repair, power/exclusion pathway, portfolio/knowledge-check preparation.
- Module 3: actor mapping, root-cause/capacity-gap analysis, objective repair, activity package, intervention logic, risk/evidence choices, module challenge, portfolio snapshot.
- Module 4: implementation warning signs, participation/access repair, feedback response, actor engagement, adaptation without harm, portfolio adjustment note.
- Module 5: evidence quality, indicators, safer disaggregation, ethical storytelling, donor story request, responsible reporting, portfolio improvement plan, and 90-day action planning.

The target list identifies 33 screens or screen clusters for possible Batch 2A implementation.
