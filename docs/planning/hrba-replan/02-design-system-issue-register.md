Pattern-level issues in this register should not be patched randomly screen by screen. Each item needs a standard rule, an approved implementation layer, and regression checks.

## Cross-Cutting Content-Safe Surface Rule

No learner-facing text may sit directly on diagonal, gradient, image, or mixed-color backgrounds unless it is inside an approved content-safe container with verified contrast across desktop, tablet, mobile, high-contrast mode, and enlarged text mode.
