# HRBA Module 1 Story Visual Intake Register — First Vertical Slice

## Status

Draft v0.1 — Documentation-only intake register, not asset approval or migration

## Purpose

This register records selected Module 1 story visuals for review before any migration or implementation. It is used to test the story visual governance process for the first HRBA vertical slice.

This register does not approve assets.

This register does not migrate assets.

This register does not rename files.

This register does not optimize files.

This register does not implement course screens.

All entries remain candidates until reviewed against accessibility, safeguarding, visual consistency, performance, and template-fit requirements.

## Scope

The intake scope is limited to selected Module 1 vertical-slice visuals, especially:

- HRBA-STORY-01: Water is Life — From Complaint to Rights Claim;
- HRBA-STORY-02: The Locked Health Post — Accountability for Public Services;
- one reusable community meeting visual that may support participation/accountability screens.

Other visuals in later batches are out of scope for this first intake and should be reviewed later.

## Initial Observations

- Batch 1 visuals appear highly aligned with the premium HRBA visual direction.
- The visuals are human-centered and locally grounded.
- They appear suitable for story-based learning, especially the Module 1 vertical slice.
- They should not be migrated yet.
- All require optimization and responsive variants before implementation.
- Evidence-board visuals need special accessibility handling because embedded details may become unreadable.
- The reusable community meeting scene is promising for participation/inclusion, but must be reviewed carefully for dignified disability inclusion.

## Crosswalk to Standards

This intake follows the Story Visual Integration Standard by linking each candidate to story ID, story title, module, screen placement, asset role, learning purpose, screen template, learning block, accessibility metadata, performance needs, safeguarding level, and follow-up action.

It follows the Premium Visual Experience Standard by treating story visuals as premium learning assets while protecting accessibility, performance, and visual consistency.

It follows the Asset Migration Register by keeping every item in candidate status and avoiding asset movement, approval, renaming, optimization, or final implementation paths.

It follows the QA Gates by keeping the task documentation-only, recording risks, and requiring build verification before commit.

It follows the Screen Template Register by mapping visuals only to approved templates such as Split Story Anchor Screen, Case Story Screen, Cinematic Module Intro Screen, Case File / Evidence Board Screen, Reflection / Portfolio Screen, and approved future template slots.

It follows the Learning Block Register by mapping visuals to approved learning blocks such as Case Story Block, Risk-Spotting Block, Hotspot / Labeled Graphic Block, Checklist / Action Plan Block, and Reflection / Portfolio Capture Block.

## Out-of-Scope Assets

The remaining Batch 2 to Batch 5 visuals are not reviewed in this intake. They should be handled in later intake registers for Module 3, Module 4, Module 5, and capstone/portfolio visuals.

## Required Follow-Up Decisions

- confirm final vertical slice screens;
- confirm whether M1-S02 and M1-S06 are the first story screens;
- decide whether the Water is Life video poster will be used as media poster or alternate anchor image;
- decide whether the Health Post evidence board should be static image, SVG, or UI-rendered case-file board;
- add final alt text and long descriptions;
- define file-size targets;
- create responsive desktop/tablet/mobile variants;
- decide actual migration source and destination paths after approval.

## Stop Conditions

Work must stop before migration if:

- any image lacks learning purpose;
- asset role is unclear;
- story/screen mapping is unclear;
- safeguarding concern is unresolved;
- alt text or text alternative is missing;
- performance plan is missing;
- image would force a one-off layout;
- image requires unapproved CSS, tokens, themes, components, or template changes.

## Final Commitment

This intake register is a review tool, not an approval list. Story visuals should enter the clean HRBA course only after they are mapped, accessible, optimized, visually consistent, and assigned to approved template slots.
