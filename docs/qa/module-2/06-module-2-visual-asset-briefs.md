# Module 2 Visual Asset Briefs

## Purpose

This file lists the visual assets recommended for Module 2 based on the QA review. These assets are intended to improve visual clarity, learning engagement, accessibility, and the overall premium feel of the HRBA e-learning course.

## Visual style direction

All visuals should follow the HRBA course visual identity:

- clean, modern, premium e-learning style
- respectful and human-centered
- suitable for local CSOs in Ethiopia / East Africa
- no stereotypes
- no dramatic humanitarian imagery
- no charity-poster feeling
- clear instructional purpose
- accessible contrast
- consistent with deep navy, pale mint, white, soft teal, and muted warm accents
- visually calm, professional, and easy to understand

## High priority assets

### 1. `m2-s04-rights-dimensions-hotspot.svg`

Screen:
- M2-S04 — Rights Dimensions Hotspot

Asset type:
- Scalable hotspot diagram

Recommended format:
- SVG preferred
- responsive 16:9 or flexible vector layout

Purpose:
- Help learners visually identify multiple rights dimensions in a single project scenario.
- Improve clarity compared with a static or generic image.
- Support hotspot placement and accessibility.

Content should represent:
- Information
- Access
- Voice
- Inclusion
- Responsibility
- Accountability / response

Design notes:
- Use clear zones for hotspot placement.
- Avoid placing critical labels over busy areas.
- Ensure each hotspot area can be visually understood.
- Use subtle icons or visual cues for each rights dimension.
- Keep the image instructional rather than decorative.

Accessibility notes:
- Requires meaningful alt text or adjacent long description.
- Hotspot labels must remain readable at smaller screen widths.

### 3. `m2-s18-power-exclusion-hotspot-bg.png`

Screen:
- M2-S18 — Power and Exclusion Hotspots

Asset type:
- Custom hotspot background illustration

Recommended format:
- PNG or WebP for rich illustration
- SVG acceptable if using simplified instructional style
- 16:9
- high resolution

Purpose:
- Help learners see how power shapes participation before a final decision is made.
- Support hotspot areas on information, entry, understanding, voice, credibility, and influence.

Scene concept:
- A cooperative or community decision-making setting.
- Everyone is invited, but power is uneven.
- The visual should quietly show that different people have different levels of information, confidence, safety, language understanding, credibility, and influence.

The image should support six hotspot areas:
1. Information — who heard early and came prepared.
2. Entry — who can enter or feels welcome.
3. Understanding — who understands the rules, terms, or process.
4. Voice — who can speak safely or disagree.
5. Credibility — whose ideas are believed.
6. Influence — who shapes the final decision.

Design notes:
- Avoid stereotypes and dramatic humanitarian imagery.
- Show ordinary learning/community context.
- Make the power imbalance visible but respectful.
- Leave clear visual spaces for hotspot markers.
- Avoid overly busy backgrounds.

Accessibility notes:
- Hotspot text must sit inside solid or semi-transparent containers.
- Provide long description of the scene and the six power dimensions.

## Recommended production workflow

Use this workflow:

1. Designers or AI image generation create the priority assets.
2. Codex places the final files in a clean asset structure.
3. Codex imports and integrates the assets into the correct screens.
4. Codex adds alt text or long descriptions.
5. Codex tests responsiveness and build.
6. Codex commits and pushes.

Recommended asset folders:

```text
src/assets/images/module-2/
src/assets/illustrations/module-2/
src/assets/icons/module-2/
```

## Integration note for Codex

Codex should not generate large realistic illustrations unless explicitly requested. Codex can create SVG diagrams and icon sets, but premium scene illustrations should be generated separately and then integrated.
