## 2. Similar-pattern risk scan

- Module 2 nearby screens use several dense custom interaction patterns, including reveal cards, maps, side panels, progress cards, and gated "complete all" mechanics. M2-S06, M2-S15, M2-S17, M2-S18, and M2-S19 are the clearest Slice 1 examples of this risk.
- The design-system issue register already flags practice instructions, dense/hidden feedback, hotspot/diagram visuals, unclear gated Continue states, portfolio checkpoints, and systematic mobile/accessibility evidence as recurring issues.
- The screen-family standardization plan recommends a worked example -> guided choice -> feedback -> independent action pattern for complex practice activities. Slice 1C applies this locally in Module 2, but the same pattern should be standardized before broad use in Modules 3-5.
- Similar portfolio checkpoint density is likely to recur in later portfolio/action-plan screens. The safest future pattern is a smaller task surface: sample first, one learner action, safety note, save state.
- Hotspot-style visuals may recur in actor maps, diagrams, MEAL/evidence visuals, and later module visual screens. These should use a common small-marker plus explanation-panel pattern rather than screen-by-screen overlay fixes.

## 3. Recommended simpler interaction patterns

- One task per step: avoid asking learners to parse a scenario, select a tab, choose a category, interpret side feedback, and track progress all at once.
- Worked example first, then learner task: keep the example visible above or beside the first learner action, not hidden in a long header paragraph.
- Two-column layout instead of three-column: use left/context and right/action, with feedback below the active task when space is tight.
- Small numbered hotspots with explanation in side panel: keep the image inspectable and place detailed text outside the visual.
- Staged diagnosis then repair: for accountability tasks, first identify the broken stage, then choose the safest repair, then read feedback.
- Short feedback card instead of dense side panel: make feedback adjacent to the learner decision and concise enough to scan.
- Portfolio sample plus one learner action field: reduce density by separating safe sample, learner input, privacy reminder, and save confirmation.
- Completion guidance next to progress: state exactly what unlocks Continue, especially when the CTA is disabled.
