# Module 1 Block Storyboard

## Storyboard summary

| Section | Screens/blocks | Learning purpose |
|---|---:|---|
| Section 1 — Welcome and Safe Start | 10 | Orient, reassure, explain course flow, introduce portfolio, establish safety |
| Section 2 — Why HRBA Matters for Local CSOs | 5 | Show HRBA relevance and connect to learner context |
| Section 3 — The First HRBA Shift | 5 | Teach beneficiary-to-rights-holder shift and practice better questions |
| Section 4 — Charity, Needs, Service Delivery, Rights-Based Practice | 4 | Distinguish HRBA from other framings |
| Section 5 — Rights-Holders, Duty-Bearers, and CSO Role | 5 | Map HRBA actors and clarify CSO role |
| Section 6 — HRBA Starting Point Self-Assessment | 10 | Complete private survey, receive feedback, select priorities |
| Section 7 — Portfolio, Quiz, Next Step | 5 | Save checkpoint, complete formative quiz, transition to Module 2 |
