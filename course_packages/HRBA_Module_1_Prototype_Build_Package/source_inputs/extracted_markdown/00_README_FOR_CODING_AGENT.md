# Module 1 AI Coding Agent Package — README

## Package purpose

This package contains the clean implementation content for **Module 1: Starting Your HRBA Learning Journey — From Good Intentions to Rights-Based Practice** in the course **Applying the Human Rights-Based Approach (HRBA) in CSO Practice**.

Use these Markdown files as the source of truth for building Module 1 with an AI Coding Agent or another course-player implementation environment.

## What this package includes

1. `01_MODULE_1_OVERVIEW.md` — module identity, purpose, learning outcomes, section flow.
2. `02_MODULE_1_SCREEN_BY_SCREEN_CONTENT.md` — exact learner-facing text for each screen.
3. `03_MODULE_1_BLOCK_STORYBOARD.md` — screen/block storyboard with block type, purpose, interaction, completion, privacy, accessibility, and assets.
4. `04_MODULE_1_INTERACTION_LOGIC.md` — deterministic behavior rules and pseudo-logic.
5. `05_MODULE_1_SELF_ASSESSMENT_SURVEY.md` — 16-item HRBA self-assessment, scoring, feedback, privacy, and portfolio-save rules.
6. `06_MODULE_1_REFLECTION_PORTFOLIO_LOGIC.md` — private HRBA Learning Portfolio logic and saved fields.
7. `07_MODULE_1_ASSESSMENT_AND_FEEDBACK.md` — all formative checks, option-level feedback, and quiz rules.
8. `08_MODULE_1_SAFETY_ACCESSIBILITY_AND_DATA_RULES.md` — safety, privacy, data minimization, accessibility, and low-bandwidth rules.
9. `09_MODULE_1_ASSET_PLACEHOLDERS_AND_ALT_TEXT.md` — asset placeholder register and alt-text requirements.
10. `10_MODULE_1_BUILD_ACCEPTANCE_CRITERIA.md` — QA checks for implementation.

## Binding implementation rules

- Build only the learner-facing Module 1 course experience.
- Do not include QA history, evidence packs, change logs, source inventories, internal reviewer notes, or previous prompt records in the learner-facing platform.
- Do not invent asset filenames or paths.
- Do not expose screen IDs or block IDs to learners.
- All Module 1 checks are formative only.
- Certificate eligibility remains tied only to the final course test with a score of **80% or above**.
- Do not request names, real cases, complaint records, safeguarding information, beneficiary lists, confidential documents, political details, or raw organizational data.
- Reflections, portfolio inputs, and HRBA self-assessment results are private by default.
- Use “Not quite” instead of “Incorrect.”
- The Module 1 quiz must contain no more than five multiple-choice questions.
- All interactions must be keyboard accessible, tap-friendly, screen-reader readable, and usable in low-bandwidth settings.
