# HRBA Implementation Sequence After Design Lock

## Sequence

1. Lock improved design specification.
2. Create module audit matrix.
3. Audit Module 1 first.
4. Repair Module 1 content, storyboard, block logic, visuals, tools, safety, and assessment.
5. Build Module 1 prototype.
6. QA Module 1 and lock production standard.
7. Audit Modules 2–9.
8. Repair content/storyboard/assets/tools/assessment module by module.
9. Build Modules 2–9 in batches.
10. Build final test and certificate pathway.
11. Configure optional practical proof separately.
12. Conduct full-course QA.
13. Publish.
14. Monitor learner use and improve after pilot.

## Rule
No full module build should start before the design lock and audit framework are approved.
