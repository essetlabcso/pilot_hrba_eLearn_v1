# 05 Module Screen and Block Rules

## Definitions

### Block
A block is an instructional unit such as a video, micro-lesson, case, scenario, quiz, tool activity, summary, or reflection.

### Screen
A screen is one focused learner-facing moment inside the player.

### Sub-Screen / State
A sub-screen is a state inside a block, such as a modal, selected tab, revealed card, feedback panel, overlay, or branching path.

## Rule 1 — A Block May Contain Multiple Screens
Examples:

- Help block: overlay screen + accessibility modal.
- Scenario block: situation screen + decision screen + feedback screen + consequence screen.
- Case study block: intro screen + case description modal + question screen + feedback state.
- Summary block: tab 1 + tab 2 + tab 3 states.

## Rule 2 — Screen Count Is Flexible
No module has a required number of screens. Agora’s 26-screen Module 1 example is not a fixed HRBA requirement.

## Rule 3 — Every Module Needs Core Structural Screens
Most modules should include:

- module cover;
- learning objectives;
- why this matters / context hook;
- core concept screen(s);
- practical activity or interaction;
- knowledge check or reflection;
- summary;
- completion.

## Rule 4 — Every Screen Has One Primary Job
A screen should mainly do one of the following:

- start module;
- orient learner;
- teach one concept;
- show one visual framework;
- ask one question;
- reveal one set of details;
- provide one case decision;
- support one tool activity;
- summarize learning;
- complete module.

## Rule 5 — Story and Scenario Use Must Match Purpose
Use:

- micro-story for hooks;
- simple case for concept application;
- scenario decision for judgment practice;
- branching scenario for complex decisions;
- tool simulation for practical output;
- capstone scenario for synthesis.

## Rule 6 — Completion Logic Must Be Explicit
Each module must specify:

- required screens/interactions;
- optional screens/interactions;
- practice check behavior;
- completion trigger;
- return-to-platform action;
- progress state update.
