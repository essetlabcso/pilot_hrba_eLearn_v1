# CSO Learning Hub HRBA Course — Improved Design Specification Lock v1.0

## Status
LOCKED FOR MODULE AUDIT AND MODULE 1 PROTOTYPE PREPARATION.

## Purpose
This package converts the UNICEF/Agora design inspiration and the HRBA course design work into a stable source of truth before module workbook audit, storyboard repair, and course build.

## Binding Position
The CSO Learning Hub HRBA course will use the UNICEF/Agora-inspired two-layer architecture:

1. **Layer 1 — Course Platform / LMS Layer** for catalogue, course overview, course roadmap, module launch, table of contents, progress, completion checkmarks, next/previous module navigation, and certificate pathway.
2. **Layer 2 — Focused Course-Player Layer** for one-screen-at-a-time learning, fixed header, left toolbar, videos, modals, glossary, resources, captions/transcripts, practice checks, feedback, summaries, completion, and return-to-platform flow.

The Agora module examples, including 6-slide Introduction and 26-slide Module 1 patterns, are design and interaction references only. HRBA module screen count is flexible and must follow the module's instructional purpose, block logic, content, scenario needs, tool activity, safety needs, and assessment requirements.
