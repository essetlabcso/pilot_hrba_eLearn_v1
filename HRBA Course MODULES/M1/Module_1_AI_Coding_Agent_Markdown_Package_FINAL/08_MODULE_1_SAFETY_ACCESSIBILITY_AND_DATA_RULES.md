# Module 1 Safety, Accessibility, and Data Rules

## Safety principle

Module 1 must be safe by default. It should help learners reflect and apply HRBA without exposing people, communities, organizations, or sensitive civic-space information to avoidable risk.

## Do not request

Never ask learners to submit:

- real names of people, staff, officials, or community members;
- real case details;
- complaint records;
- safeguarding or protection information;
- beneficiary lists;
- personal data;
- legal disputes;
- internal reports;
- confidential documents;
- political or civic-space-sensitive details;
- raw organizational data;
- uploads.

## Safe alternatives

Use:

- broad role categories;
- fictional examples;
- anonymized examples;
- general improvement priorities;
- structured choices;
- optional private notes with safety helper text;
- portfolio summaries rather than raw evidence.

## Privacy rules

| Data type | Default visibility |
|---|---|
| Safe Learning Agreement acceptance | System status only |
| Orientation check completion | Learner/system only |
| Scenario/sorting/matching completion | Learner/system only |
| Portfolio setup choices | Private to learner |
| Optional notes | Private to learner only |
| Self-assessment scores and result band | Private to learner |
| Domain scores | Private to learner |
| Priority domains | Private to learner |
| Module quiz completion | Learner/system only |
| Module quiz score | Formative only, no certificate effect |

## Certificate rule

- Module 1 checks are formative only.
- Module 1 does not issue certificates.
- Certificate eligibility remains tied to the final course test score of 80% or above.

## AI/data restriction

Raw reflections, optional notes, self-assessment notes, and portfolio content should not be sent to AI services. If AI is used later for safe summaries, it must use structured non-sensitive tags or participant-approved safe summaries only.

## Accessibility requirements

| Requirement | Rule |
|---|---|
| Transcript | Required for welcome video |
| Captions | Required if video/audio is used |
| No autoplay | Required for all media |
| Keyboard access | Required for all interactive blocks |
| Tap-first mobile | Required for all interactions |
| Screen-reader labels | Required for all buttons, radio buttons, checkboxes, rating scales, and forms |
| Non-drag alternative | Required for sorting and matching |
| Text alternative | Required for roadmap, diagrams, maps, images, icons, and charts |
| Mobile stack | Required for cards, columns, comparison blocks, and survey |
| No color-only meaning | Scores, feedback, and status must use labels and text |
| Plain language | Required throughout |
| Optional text fields | Must include safety helper text |
| Low-bandwidth fallback | Required for all media and visuals |

## Low-bandwidth rules

- Video is optional; transcript is required.
- Images are optional; alt text and text alternative must carry the meaning.
- Sorting and matching must work without heavy animation.
- Do not rely on external embedded media to complete required learning.
- Provide text-only pathways for required content and assessments.

## Form safety helper text

Use this text before optional note fields:

> Keep this safe and general. Do not include names, real cases, complaints, safeguarding details, legal disputes, political details, confidential documents, or raw data.

## Safe Learning Agreement copy

I agree to:

- use broad and safe examples;
- avoid real names of people, communities, staff, officials, organizations, or cases unless the platform specifically asks for a safe public example;
- avoid sharing complaint records, safeguarding information, beneficiary lists, personal data, legal disputes, internal reports, or confidential documents;
- avoid political or civic-space-sensitive details that could create risk;
- respect other learners and avoid judging organizations or communities;
- use fictionalized, anonymized, or general examples when reflecting;
- focus on learning and improvement, not blame.
