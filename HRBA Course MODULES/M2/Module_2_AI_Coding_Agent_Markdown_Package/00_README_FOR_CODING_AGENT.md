# Module 2 AI Coding Agent Package — README

## Package purpose

This package contains the clean implementation content for **Module 2: Human Rights in Everyday CSO Work** in the course **Applying the Human Rights-Based Approach (HRBA) in CSO Practice**.

Use this package as the source of truth for building Module 2 in the CSO Learning Hub course player or related repo implementation.

## Package files

1. `00_README_FOR_CODING_AGENT.md` — build rules, file map, no-drift instructions.
2. `01_MODULE_2_OVERVIEW.md` — module purpose, outcomes, duration, learner shift, section flow.
3. `02_MODULE_2_SCREEN_BY_SCREEN_CONTENT.md` — exact learner-facing content for all 36 screens.
4. `03_MODULE_2_BLOCK_STORYBOARD.md` — screen-by-screen storyboard with block type, learner action, completion condition, data, privacy, accessibility, and asset requirement.
5. `04_MODULE_2_INTERACTION_LOGIC.md` — deterministic behavior rules and pseudo-logic.
6. `05_MODULE_2_REFLECTION_PORTFOLIO_LOGIC.md` — Module 2 portfolio checkpoint and carry-forward logic.
7. `06_MODULE_2_ASSESSMENT_AND_FEEDBACK.md` — all formative checks, answers, and option-level feedback.
8. `07_MODULE_2_DESIGN_AND_VISUAL_SPEC.md` — visual and interaction design rules for implementation.
9. `08_MODULE_2_SAFETY_ACCESSIBILITY_DATA_RULES.md` — safety, privacy, accessibility, low-bandwidth, and data rules.
10. `09_MODULE_2_ASSET_PLACEHOLDERS_AND_ALT_TEXT.md` — asset placeholders, approved filenames, and alt text.
11. `10_MODULE_2_BUILD_ACCEPTANCE_CRITERIA.md` — implementation QA checks.
12. `11_MODULE_2_CODE_AGENT_HANDOFF_PROMPT.md` — copy/paste-ready coding-agent prompt.

## Binding implementation rules

- Build only the learner-facing Module 2 course experience.
- Do not include QA history, evidence packs, source inventories, change logs, approval locks, review notes, or production-process records in the learner-facing platform.
- Do not expose screen IDs, block IDs, source IDs, citations, or implementation metadata to learners.
- Preserve the approved seven-section sequence and 36 learner-facing screens/blocks.
- Keep all Module 2 checks formative only.
- Certificate eligibility remains tied only to the final course test with a score of **80% or above**.
- Do not request names, real cases, active complaints, safeguarding information, beneficiary lists, confidential documents, legal disputes, political details, raw organizational data, or uploads.
- Reflections, worksheet entries, optional notes, and portfolio checkpoint content are private by default.
- Do not send raw portfolio/reflection/worksheet text to AI services.
- Use “Not quite” instead of “Incorrect.”
- Use “That’s right” or “Good choice” for best responses.
- Module 2 final quiz must contain no more than five MCQs.
- Standards must be framed as practical learning and analysis tools, not legal advice.
- Worksheets must have both downloadable and in-platform accessible options.
- All interactions must be keyboard accessible, tap-friendly, screen-reader readable, and usable in low-bandwidth settings.
- Do not invent asset filenames. Use the approved source-named assets where listed; otherwise use placeholders.
