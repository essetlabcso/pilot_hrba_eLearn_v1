# Module 2 Block Storyboard

## Module identity

| Field | Final entry |
|---|---|
| Course title | Applying the Human Rights-Based Approach in CSO Practice |
| Module title | Module 2: Human Rights in Everyday CSO Work |
| Recommended duration | 75–90 minutes |
| Main portfolio output | My Everyday Rights Lens |
| Certificate rule | Module 2 checks are formative only. Certificate remains tied to final course test score of 80% or above. |
| Privacy rule | Portfolio inputs, optional notes, worksheet entries, and reflection outputs are private by default. |
| Final screen count | 36 learner-facing screens/blocks |

## Storyboard summary

| Section | Screens/blocks | Learning purpose |
|---|---:|---|
| Section 1 — Start Module 2 | 3 | Bridge from Module 1, preview outputs, establish safety |
| Section 2 — What Are Human Rights? | 4 | Define rights simply and create a safe personal explanation |
| Section 3 — Human Rights in Everyday Life | 5 | Recognize rights dimensions and map one everyday issue |
| Section 4 — Characteristics of Human Rights | 4 | Teach universal, inalienable, indivisible, interdependent rights |
| Section 5 — Types of Rights | 5 | Explore broad rights families and sort examples |
| Section 6 — Human Rights Systems and Standards | 6 | Use standards safely as practical guides, not legal advice |
| Section 7 — Connecting Human Rights to CSO Practice | 9 | Apply rights lens, save portfolio checkpoint, complete quiz, transition |
